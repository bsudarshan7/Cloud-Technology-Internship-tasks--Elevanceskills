Automated CI/CD Pipeline Architecture

Built automatically via GitHub Webhooks, Jenkins Declarative Pipeline, Docker Engine, and Docker Hub Registry.

1. Source Control (GitHub)

Code commits pushed to the main branch immediately dispatch a JSON webhook payload to Jenkins.

2. CI Orchestration (Jenkins)

Declarative Jenkinsfile checks out the latest commit and executes containerized build stages automatically.

3. Container Build (Docker)

Packages static assets into a lightweight nginx:alpine container image tagged with the Jenkins build number.

4. Artifact Registry (Docker Hub)

Pushes versioned and latest container images securely to the instantprachi namespace.
